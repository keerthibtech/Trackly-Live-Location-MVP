# 📍 Trackly – Live Location Tracker

Trackly is a GPS-based live location tracking MVP built using HTML, CSS, JavaScript, and Leaflet.js.

## 🚀 Features

- Get current device location
- Display latitude and longitude
- Show location on an interactive map
- Start and stop location tracking
- Live tracking status

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap.

## 🎯 Project Goal

A simple MVP demonstrating how a web application can access a user's location with permission and display it on an interactive map.

## ⚠️ Note

This is a prototype created for learning and hackathon preparation. Location tracking requires user permission.
